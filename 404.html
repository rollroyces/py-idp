About this service

A web wrapper around py-idp — a six-stage document-intelligence pipeline. Runs locally; no data leaves your machine.

Endpoints

  • POST /extract · upload → fields + confidence
  • GET /templates · list templates
  • GET /templates/{name} · template + Markdown
  • POST /api/correct · save HITL correction
  • GET /api/history · past runs (last 50)
  • GET /api/corrections · saved corrections
  • /healthz · /readyz · /version · /metrics

Backends

  • mock · zero-config, no API keys
  • ollama · local models
  • openai · anthropic · cloud APIs
  • china:<name> · 8 China LLMs
  • hf-vlm · self-hosted OCR

Schemas

  • Invoice · Contract · BankStatement · Receipt
  • Or bring your own Pydantic schema
